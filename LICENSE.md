This repository contains the client for the QuietPhysics GitHub Action
("the Action"), which connects to the QuietPhysics Cloud API
(https://quietphysics.com). It is provided so the Action's source can be
reviewed by anyone deciding whether to install it, and so it can be
referenced directly (`uses: Evgsoft/quietPhysics-github-marketplase@...`)
from a GitHub Actions workflow.
